## 为什么要做这个工作

在长时程运行的强化学习智能体中,存在一个长期被观察、却从未被命名、形式化或可测量的现象:

> 智能体一旦学会某个高奖励的(状态,动作,奖励)模式,就会"走不开"——
> 即使当前任务已不再奖励该模式,智能体仍反复回到该模式。

学界虽在"奖励黑客"(reward hacking)、"插头化"(wireheading)、"行为塌缩"(behavioral sink)、"模式崩溃"(mode collapse)等标题下零散讨论过类似现象,但**没有一篇工作把它作为独立对象进行命名、形式化、可观测度量与跨学科桥接**。本文做了这四件事:

1. **命名**:将这一现象命名为**任务引力(Task Gravity)**。
2. **形式化**:证明它是策略参数空间中朗之万随机微分方程(SDE)的**吸引盆(basin of attraction)**,定义**引力算子** G(θ) 作为可计算的时间平均奖励-策略对齐量。
3. **度量**:提出两个**轻量、轨迹级、无需修改智能体**的指标——**TRR**(Trajectory Revisitation Rate,轨迹回访率)与 **CTRR**(Cross-Task Return Rate,跨任务回归率)。
4. **跨学科桥**:证明任务引力与人类强迫行为(成瘾、强迫症、抑郁反刍)是**形式同构**——批评网络(critic)在功能上等价于基底神经节多巴胺通路,从而打开跨学科合作大门。

## 关键实证结果(可复现)

我们提供完整开源参考实现(NumPy + Stable-Baselines3),在两套独立环境下得到一致的 Task Gravity 签名:

- **表格基线(3 任务,偏置奖励)**:噪声从 0 升到 0.7 时,CTRR 从 0.01 跃升至 **1.0**;贪心 Q 学习智能体访问过的不同状态数从 7 跌至 **3**。
- **深度 PPO 智能体(向量观测,3 任务)**:CTRR 随训练期噪声单调上升;在训练噪声 = 0.7 下学到的策略,即使评估时给干净信号也**无法路由**(CTRR = 0.33),且在被迫执行非吸引子任务时**超出步数预算**(轨迹长度顶到 660)。这正是"训练一次、锁定终身"的实证证据。

整套实验可在 CPU 笔记本上 < 3 分钟内复现,代码完全开源(MIT)。

## 我们不宣称什么

本文是立场报告(position paper),**不**宣称:
- 给出了任务引力的封闭形式解;
- 给出了统一的强迫症理论;
- 在 Procgen / MiniGrid 上达到了 SOTA。

我们**仅**宣称:**一组词汇 + 两个度量 + 一个可证伪的理论桥梁**。实证是示意性的,基准性扩展邀请社区参与。

## 投稿信附:常见审稿意见预案

**审稿人**:这只是 reward hacking 换了个名字。
**回应**:本文有三点严格超过既有 reward hacking 文献:
(1) 朗之万 SDE + 引力算子的形式化;
(2) CTRR 作为无需访问奖励函数的轨迹级黑盒度量;
(3) 与人类强迫症的同构,生成可证伪预测(OP-4),这是 reward hacking 完全没有的。

**审稿人**:实验规模太小,只有 3 个任务。
**回应**:这是 position paper 的标准规模。关键效应在 3 任务下已显现,tabular + PPO 两套独立实现相互印证。扩展计划见 OP-3(64 任务语料)。

**审稿人**:命名是否与现有概念重叠?
**回应**:见论文附录 B 的术语映射表,Task Gravity 与现有概念互不等价。命名新概念本身是 position paper 的合法贡献;指标 TRR/CTRR 首次提出,不存在重名问题。
