## Author Bio (English, 100 words)

The authors study long-horizon agents and their failure modes, with
a particular interest in phenomena at the boundary of reinforcement
learning, cognitive science, and AI safety. This position paper
is part of an ongoing effort to provide the field with a shared
vocabulary for the patterns that emerge when agents run for hours,
days, or indefinitely. We welcome collaboration on empirical
benchmarks (Open Problem OP-3) and on the human-compulsion analogy
(Open Problem OP-4). Correspondence:
[task-gravity@example.org](mailto:task-gravity@example.org).

## Data Availability Statement

**Data:** No external datasets were used. All empirical results are
generated by the reference implementation included with this submission.

**Code:** Fully open-source, MIT licensed. Available in the supplementary
zip under `experiment/`. The Tabular baseline requires only NumPy; the
deep PPO reproduction requires `gymnasium>=1.0`, `minigrid>=3.0`,
`stable-baselines3`, and `torch`. Total run-time on a CPU laptop:
< 5 minutes.

**Reproducibility checklist:**

| Item | Status |
|------|--------|
| Random seeds declared | Yes (in `experiment/src/experiment.py`) |
| Hyperparameters logged | Yes (in `experiment/src/train.py`) |
| Dependencies pinned | Yes (`experiment/requirements.txt`) |
| Hardware specified | CPU-only reproduction |
| Wall-clock time reported | < 5 min tabular, ~3 min deep |
| Outputs hashable | CSV with stable column order |

## Reproducibility Appendix (single-column summary)

The full reproducibility package is structured as:

```
submission/
├── paper.pdf              # final camera-ready (when compiled)
├── paper.md               # source
├── paper.html             # HTML for web distribution
├── cover_letter.md        # English
├── cover_letter_zh.md     # Chinese
├── keywords.md            # this file
├── open_problems.md       # 6 concrete follow-ups
├── venues.md              # target submission venues
└── supplementary/
    ├── README.md          # how to reproduce
    ├── LICENSE            # MIT
    ├── experiment/        # tabular + deep code
    │   ├── src/...
    │   ├── results/...
    │   └── requirements.txt
    └── requirements.txt   # merged dependencies
```

To reproduce all figures:

```bash
cd supplementary/experiment
python -u -m src.experiment            # tabular
python -u -m src.plot
cd deep
python -u -m src.run --timesteps 10000 # PPO
python -u -m src.plot
```
